- 기존 기획서 62페이지 중 8페이지의 물품 위치·진행 순서·체크포인트를 갱신하고 입구/HUD·옥상 진입부를 실제 SDL 화면으로 바꿨다. 수정 페이지 렌더링과 구조 검증을 마쳤으며 다른 슬라이드·레이아웃·발표 PPT는 유지했다.

- 실제 SDL 비교에서 일반/강화 정면 질주는 체력 2, 예고 후 점프·후퇴는 체력 3·배터리 100, Q 대응은 체력 3·배터리 80, R 대응은 체력 3·배터리 50을 확인했다. 새 시작 배치에서도 주택가 8마리 왕복→복구→출구→관리소 강화까지 사망 없이 재통과했다. 자동 입력 비교는 허점·진행 검증이며 체감 난이도 확정을 뜻하지 않는다.

- 밸런스 변경에 맞춰 기존 기획서의 적 행동·빛 해제 후 재판단·주택가 보급·진행·실제 화면 9페이지를 갱신했다. 62페이지·기존 양식을 유지하고 변경 페이지 렌더링·패키지·배치 검증을 통과했다.

- 실제 SDL에서 선택 보급고 우회부터 첫 상승 발판 재등반·8마리 교전·퓨즈 왕복·복구·출구·집광 강화·추가 조각으로 광탄 구매까지 사망 없이 통과했다. 기존 보급고 생략 경로도 재통과했다. 별도 SDL 비교로 치료제/광탄 구매·수량 최대·잔액 부족·키 유지·재방문·시간 정지·재시작을 검증했다. 자동 조작 결과를 일반 플레이 시간·난이도로 해석하지 않는다.

- 선택 보급고 개봉과 적의 치명타가 같은 갱신에 겹쳐도 조각·개봉 기록이 한 번만 유지되는 것을 검증했다. 기획서 9페이지의 보급고·관리소·현재 범위와 실제 구매 화면을 갱신하고 62페이지·기존 양식·다른 슬라이드를 보존했다. PRD와 PPT는 파일에 저장하고 이번 커밋에서는 제외한다.
