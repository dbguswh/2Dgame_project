# 개발 이어가기 기록

갱신: 2026-11-13

## 이번 작업 완료

- 조명 후퇴 뒤 정지하던 동작을 어둠 순찰로 변경했다. 실제 어두운 바닥에서 양쪽으로 걷고 빛 경계에서는 돌아선다.
- 생성 위치 주변 44픽셀 순찰 대신 전투 구간과 실제 바닥을 사용한다.
- 상승 발판 → 옥상 적 구간 → 퓨즈 → 하강 적 구간 → 배터리 → 제어함 → 교량의 동선으로 바꿨다.
- 퓨즈를 먼저 얻고 아래 통로로 내려가 위층 적을 건너뛰던 구조는 제거했다. 처치 강제 조건은 추가하지 않았다.
- 대형 교량의 2.4초 전개와 안전 차단봉은 유지한다.
- Shift 달리기(208픽셀/초)와 전용 6프레임을 추가했다. 점프 높이·중력·피격 판정은 유지한다.
- 0.65초 고정 조준 뒤 그림자 탄을 쏘는 원거리 Shade를 추가했다. 예고·발사·회수 자세, 벽·빛 충돌, 실제 달리기·점프 회피를 연결했다.
- 적은 8마리(근접 5·원거리 겸용 3), 구간별 2/3/3이다.
- 교량·제어함·출구를 높이 224픽셀로 옮겼다. 지상에서는 조작·출구 이동이 되지 않는다.
- Q 섬광을 추가했다. 배터리 20·재사용 0.6초·전방 96픽셀·가까운 한 명 피해 1이다. 전용 손목 발사 6자세와 짧은 금빛 효과를 사용한다.
- 명중한 적은 현재 근접 타격·원거리 발사를 취소하고 최대 48픽셀 밀린 뒤 1.2초 제압된다. 벽·발판 끝은 넘지 않는다. 이미 발사한 탄은 남는다.
- Q→달리기→W 마무리, Q 2회 처치, R/Q/W 동시 입력 우선순위, 공중 궤적과 지상 동작 잠금을 연결했다.
- 복구 전 월드를 어둡게 하고 기본 랜턴은 약한 이동 시야, R은 반경 160픽셀의 강한 고정 시야로 구분했다. 랜턴은 적을 억제하지 않는다.
- 영구 복구 시 1.2초 동안 구역 전체 점등을 전개한다. 기존 복구 판정·2.4초 다리 전개 시간은 유지한다. 발판 윤곽·적 예고·조준선·탄·명중 효과와 HUD는 별도 표시한다.
- PRD 9.4절과 기존 기획서 PPT의 조명 역할·핵심 재미·2/5주차 계획을 맞췄다. 기획서 5페이지에 어둠·랜턴·R·영구 복구 설명을 추가했다.
- 상승 발판의 아래·옆면에 갇히던 문제를 수정했다. 해당 얇은 발판은 아래·옆으로 통과하고 하강 시 윗면에 착지한다. 지상에서 첫 발판으로 돌아가 다시 옥상에 올라갈 수 있다.
- 교량 양쪽 바닥에 144·192픽셀 복귀 발판을 두고 교량 접근 발판도 아래에서 올라가게 했다. 벽·천장·보급 발판은 기존 충돌을 유지해 지상으로 필수 전투 동선을 우회하지 못한다.
- R을 반경 5타일·12초·비용 50의 휴대 투광기로 강화했다. 전개 직후 주변 적을 최대 96픽셀 밀고 공격·조준을 취소한다. 피해는 주지 않으며 늦게 진입한 적에게 설치 파동을 반복 적용하지 않는다.
- 강한 밀림 이후 어둠까지 후퇴하고 바깥에서 순찰한다. 벽·발판 끝에 막히면 몸을 낮추고 0.35초 간격으로 탈출 경로를 재확인한다. Q 제압을 받으면 이전 투광기 밀림을 취소해 늦게 겹치지 않는다.
- 설치 지점의 벽·바닥·천장으로 빛 영역을 잘라 다른 방·층을 보호하지 않게 했다. 장치는 56픽셀, 넓은 반사광·0.55초 바닥 파동·6칸 표시등을 사용하고 탄 차단 시 0.32초 파편을 표시한다.
- 기획서의 조명 표현·장비·조작키·적 반응·코어 강화·개발 계획을 같은 수치로 맞췄다. 기존 62페이지와 양식·이미지는 유지한다.

- 주택가 8개 생성 지점에 9초 대기·1초 예고·128픽셀 안전 거리·R 동결·영구 종료를 연결했다. 죽은 위치가 아닌 원래 지점에 같은 적을 재사용해 보충한다.
- 예고 중 점등·근접 시 취소 후 1초 예고를 다시 시작한다. 균열·입자·Shade 실루엣·예고 막대와 0.35초 출현 발광을 표시한다. 조명 만료 갱신은 어두운 부분의 시간만 대기에 반영한다.
- 사망·재시작은 기존 초기 적 복원과 생성 대기 초기화를 함께 처리한다. 복구된 구역은 봉쇄 상태를 유지한다. 새 적은 다음 갱신부터 정상 예고를 거쳐 공격하며 처치 보상은 없다.

## 확인한 내용

- 단위·통합 테스트 251개 통과.
- 실제 SDL 키 입력으로 주택가 완주·사망 복귀·배터리 획득·교량 전개 일시정지·완료·재시작 확인.
- 지상·옥상에서 각각 7.5초 동안 후퇴 후 양방향 순찰 확인. 어둠 순찰 중 정지 프레임 0.
- 정지 시 원거리 피해, 달리기+점프·조준 중 뒤로 달리기 회피를 실제 SDL 입력으로 비교했다. 현재 옥상 혼합 교전에서도 무적 없이 탄을 피했다.
- 8마리·위층 교량의 필수 경로 완주도 확인했다. 기존 PPT 삭제 2건은 사용자 작업이며 스테이징하지 않는다.
- Q는 실제 SDL 키 입력·렌더링으로 좌우 6자세, Q→달리기→W 처치(배터리 80·체력 3), 발사 직전 원거리 취소·일시정지 동결을 확인했다.
- 테스트로 동일 갱신의 근접·원거리 공격 취소, 벽·발판 끝의 밀림 제한, 제압 만료 후 새 예고, R 후퇴 재개, 이미 날아온 탄의 피격, 사망 시 배터리 소비 보존을 확인했다.
- 어둠 마스크의 이동 좌표·약한 랜턴/강한 R 대비·영역 가림·만료·전체 복구를 검사했다. 실제 SDL 화면으로 각 상태를 비교했고 주택가 필수 경로와 원거리 달리기/점프 회피도 다시 통과했다.
- 실제 SDL 키 입력으로 발판 사이 낙하→첫 발판 복귀→옥상 재등반, 교량 양쪽의 지상→224픽셀 복귀를 확인했다. 체력 3·사망 0을 유지했다. 필수 경로 완주·다리 전개·보상 1회·재시작도 통과했다.
- 강화된 투광기를 실제 SDL 입력·렌더링으로 확인했다. 큰 밀림 후 적 체력 2 유지, 날아오던 탄 차단·파편, 배터리 50·플레이어 체력 3, 일시정지·소등 종료를 검증했다. 주택가 전체 경로도 재통과했다.
