# Blackout

Python과 pico2d로 개발하는 횡스크롤 2D 탐색·퍼즐 액션 게임.
게임 규칙과 개발 순서는 [PRD.MD](PRD.MD)에서 관리한다.

## 실행

Python이 설치된 환경에서 이 프로젝트 폴더의 터미널을 열고 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지 경로는 소스 파일의 위치를 기준으로 찾으므로 다른 폴더에서 실행해도 된다.
타이틀에서 위/아래로 선택하고 E로 시작한다.
플레이 중 Esc를 누르면 계속하기·스테이지 재시작·타이틀로·나가기를 선택할 수 있다.

## 현재 구간 확인 순서

1. 타이틀에서 E로 시작한다. 입구에 무료 보급은 없으며 체력 3·배터리 100·광검으로 첫 교전을 통과한다. 적 돌진 예고를 보고 점프·후퇴하거나 Q/R로 끊는다.
2. Shade와 W로 전투하거나 R로 조명을 설치해 후퇴하는 반응을 확인한다.
   Space로 점프한 뒤 W를 누르면 전방 아래쪽을 한 번 벤다. 착지 후 새 W 입력으로 지상 공격을 이어갈 수 있다.
3. 첫 교전 뒤 첫 발판 (832,144)의 치료제를 회수하고 피해 시 1/F로 사용한다. 상승 발판을 올라 중앙 제어함과 퓨즈 부족 안내를 확인한다. 하부 선택 경로 (1040,96)에는 속도 보급이 있다.
4. 옥상 진입부 보급함에서 광탄을 회수해 교전에 활용하고, 옥상 끝 배터리 팩을 확보한다. 3번으로 선택하고 F를 유지해 충전하며 ←/→ 방향·↑/↓ 각도를 조절하고, F를 놓아 던진다. 지형 접촉 폭발은 반경 48픽셀의 여러 적에게 피해 1과 공격 취소를 적용한다. 옥상 비행형의 예고를 피해 반격하고 낮은 연결 발판을 거쳐 동쪽 정비실에서 복귀 배터리와 퓨즈를 회수한다. 아래 골목에는 지상 적 2마리·치료제가 있으며 동쪽 발판으로 위층과 왕복할 수 있다.
5. 왼쪽 중앙 제어함으로 돌아온다. 살아 있는 적·재출현한 적을 상대하며 R로 복귀 공간과 생성 억제 시간을 확보한다.
6. 중앙 제어함에 E로 퓨즈를 설치한다. 구역 점등·적 소멸·재출현 종료 후 카메라가 원격 교량으로 이동해 2.4초 전개를 보여주고 돌아온다. 전체 3.6초 동안 월드·효과·플레이 시간은 멈춘다. Space로 건너뛰고 Esc로 일시정지한다.
7. 밝아진 옥상·정비실을 지나 교량을 건너고 출구 E로 완료 화면에 진입한다. 새 E로 도시 지도, 다시 새 E로 관리소에 들어간다.
8. Esc 메뉴에서 일시정지와 재시작을 확인한다. 재시작하면 획득·복구·보상·자원을 모두 구간 진입 당시로 되돌린다.

E 설비 복구는 배터리를 사용하지 않는다. R의 12초 조명과 달리 복구 상태는 사망해도 유지된다.
퓨즈 없이 E를 누르면 필요한 부품을 안내한다. 운하는 12타일(384픽셀) 폭이며, 기본 점프와 속도 30% 증가로도 복구 전 다리를 우회할 수 없다.

## 현재 구현

- 기본 표시 창 1440×810. 작은 모니터에서는 사용 가능한 크기에 맞춤
- 복구 전에는 월드에 어둠을 적용하고 기본 랜턴이 주변만 약하게 드러냄. 랜턴은 배터리 소모·적 억제 없음
- R의 실제 160픽셀 억제 범위에 강한 시야를 연결. 설치 위치에 고정되고 소등·만료 시 그 빛만 사라짐
- 전력 복구 시 1.2초 동안 구역 전체의 어둠이 걷힘. 적 소멸은 즉시 적용하고 다리 통행은 2.4초 전개 완료 후 허용
- 발판 윗면·끝 윤곽과 공격 예고·조준선·탄·명중 효과·HUD는 어둠 밖에서 별도로 표시
- 창 테두리를 드래그해 크기 조절 가능. 화면 비율과 게임 좌표 960×540 유지
- 확정한 Warden 대기 이미지와 6프레임 걷기 시트: 캐릭터 높이 약 96픽셀
- 발바닥을 기준으로 한 배치와 몸통 충돌 영역의 초기 크기 정의
- ←/→로 좌우 이동, 이동 방향에 맞춰 이미지 반전, 키를 놓으면 정지
- Shift를 누르며 이동하면 초당 208픽셀 달리기. 전용 6프레임과 실제 이동 거리 기준 보폭 사용
- 달리기 중 점프의 높이·중력은 같고 수평 거리가 늘어남. 무적·체력 회복·배터리 소비는 없음
- Space로 약 2타일 높이 점프. 공중 방향 전환, 중력과 바닥 착지
- 수직 속도에 따라 상승·정점·하강 이미지 전환, 착지하면 대기·걷기로 복귀
- 잔광 코어의 금빛 광검을 기본 무기로 사용. 가로·올려·공중 내려 베기 총 18자세와 칼날 생성·회수, 금빛 참격·잔상·방향별 명중 베기선 연결
- 지상 판정 높이는 발 기준 1타 +12~+80픽셀, 2타 +12~+112픽셀. 벽·천장·공중 바닥 가림을 반영하며 타격당 가까운 한 명·피해 1·배터리 무소비 유지
- 참격 잔상은 짧은 시각 효과이며 추가 피해·투사체·조명 억제 없음
- W로 지상 1타, 시작 후 0.4초 안에 W를 다시 눌러 올려베기 2타 연결. 각 타격에 전용 6프레임 사용
- 준비 0.10초·타격 0.10초·회수 0.16초로 재생하고, 공격 중 이동·점프 중복 방지
- 2타는 준비 0.12초·타격 0.12초·회수 0.20초. 미리 입력한 2타는 1타 동작이 끝난 뒤 시작
- 2타 후 0.5초 대기. 키 누르기 반복으로 자동 연격하지 않으며 세 번째 타격은 예약하지 않음
- 2타 명중 시 적을 약 1타일 밀어냄. 벽·발판 끝·전투 구간 밖으로 밀지 않고 사망 시에도 짧은 밀림 표현
- 준비 자세를 길게 읽히고 타격 자세로 빠르게 전환. 발 기준으로 상체가 뒤로 힘을 모았다 앞으로 기울어지는 시각 회전
- 실제 W 명중 때만 공격자와 맞은 적에 0.04초 정지, 2타는 0.055초·처치는 0.065초. 빈 공격에는 정지 없음
- 명중 교차 지점에 짧은 금빛 섬광과 보라색 그림자 파편. 2타·처치에만 최대 2~3픽셀의 짧은 수평 화면 흔들림
- 히트스톱은 두 배우의 동작·이동·공격 시간만 멈추며 조명 수명·맵 설비·다른 적·플레이 시간은 계속 진행
- 히트스톱 도중 새로 누른 W는 재개 시 처리. 피격·사망·재시작 시 공격자의 정지 상태도 해제
- 타격 구간에서만 몸통 앞끝부터 전방 80픽셀(2.5타일) 판정. 벽 너머 제외, 가까운 대상 한 명을 공격당 한 번 선택
- 공중 W는 전용 6프레임 내려베기. 준비 0.10초·타격 0.12초·회수 0.12초, 피해 1·배터리 소모 없음
- 공중 베기 중 좌우 이동·중력·점프 궤적 유지. 공격 방향만 고정하고 무적·추가 도약·강제 하강은 부여하지 않음
- 점프·발판 이탈부터 다음 착지까지 공중 베기 한 번. 피격·키 반복으로 사용 횟수를 초기화하지 않음
- 착지 시 공중 동작을 종료하고 새 W 입력으로 지상 1타 시작. 지상 2연격 후 대기 시간은 점프로 우회할 수 없음
- 공중 타격은 전방 80픽셀·발 기준 아래 32~위 48픽셀. 벽·발판 아래를 가려 가까운 한 명에게 한 번만 피해
- Q는 손목 장치의 섬광을 전방 3타일로 발사. 전용 6자세·짧은 금빛 부채꼴로 표현하며 가까운 적 한 명에게 피해 1
- Q 한 번에 배터리 20, 재사용 간격 0.6초. 빈 발사도 소비하고 키 유지·재사용 대기·배터리 부족에는 중복 소비 없음
- Q 명중 시 근접 타격·원거리 조준과 같은 갱신의 발사까지 취소. 적을 최대 48픽셀 밀고 1.2초 제압하며 금빛 표시와 남은 시간 막대를 표시
- 밀림은 벽·발판 끝에서 멈춤. 제압 후 빛 안이면 후퇴하고, 어둠에서는 추적·새 공격 예고부터 재개
- Q 뒤 달려가 W로 마무리하거나 Q 두 번으로 처치 가능. 이미 발사된 그림자 탄은 계속 날아오므로 점프·달리기 또는 R로 대응
- 새 전투 키가 겹치면 R → Q → W 중 하나만 처리. 기존 동작 중 다른 액션을 중첩하지 않으며 공중 Q는 점프 궤적 유지
- Space를 계속 눌러도 재점프하지 않으며 착지 후 다시 눌러야 함
- 벽·천장·계단형 발판과 몸통 영역의 충돌. 발판에서 걸어 나가면 낙하
- 낙하 시 체력 1 감소와 마지막 안전 발판 복귀. 체력 소진 시 지정 안전 지점·체력 3으로 복귀
- 낙하 복귀 후 1초 깜빡임. 복귀 직후에는 방향키를 다시 눌러 이동
- 경과 시간 기준 초당 128픽셀 이동, 맵 바깥 이동 제한
- 양쪽 방향키를 함께 누르면 정지. 창이 비활성화되면 이동 입력 해제
- 창이 비활성화된 동안 이동·적 행동·공격·효과 시간을 멈춤
- 실제 이동 거리에 맞춰 걷기 재생. 키를 놓거나 화면 끝에서 멈추면 대기 자세
- 프레임마다 발 기준점을 맞추고 몸통 영역은 일정하게 유지
- 세 화면 길이(2880픽셀)의 주택가와 수평 추적 카메라. 카메라는 맵 양끝에서 정지
- 지상 96픽셀, 상승 발판 144·192·240픽셀, 옥상 288픽셀, 중앙 제어함 288픽셀, 연결 발판 256픽셀, 정비실 304픽셀, 교량·출구 224픽셀로 연결
- 상승용 얇은 발판은 아래·옆으로 통과하고 내려올 때 윗면에 착지. 사이로 떨어지면 지상에서 왼쪽 첫 발판으로 돌아가 재등반 가능
- 교량 양쪽 지상에 높이 144·192픽셀의 복귀 발판을 추가. 아래에서 224픽셀 제어함·출구 높이로 돌아올 수 있으며 기존 벽·천장·보급 발판의 충돌은 유지
- 옥상 적 구간 뒤에 배터리, 동쪽 정비실 적 구간 뒤에 퓨즈 배치. 층이 다른 지상에서 아이템을 접촉 획득하지 않음
- 퓨즈 접촉 회수 후 제어함 근처 바닥에서 E로 구간 복구. 배터리 소모 없음
- 운하 폭을 기존 192에서 384픽셀로 확장. 교각·금속 상판·보강재·난간·힌지·와이어를 갖춘 양엽식 교량
- 다리는 2.4초 전개 완료 시 충돌 영역 추가와 안전 차단 해제. 사망 시 복구된 다리는 펼쳐진 상태 유지
- 배터리 팩 2개(옥상·정비실), 접촉 시 각각 최대 50 회복. 최대치일 때는 미획득 상태 유지
- 다리 복구 보상 조각 2개. 사망·E 재입력으로 중복 획득하지 않음
- 복구 시 구간 점등·적 소멸·안전 지점 확보. 사망해도 복구 상태 유지
- Shade 8마리를 첫 구간 2·옥상 3·정비실 3마리로 배치. 근접 5·원거리 겸용 3마리
- 원거리 적은 최대 384픽셀에서 발견하고 같은 구간·같은 층·시야가 열린 112~352픽셀 거리에서 조준 시작
- 0.65초 동안 조준선과 손의 발광으로 예고. 예고 시작 위치를 고정해 발사하며 이후 유도하지 않음
- 그림자 탄은 초당 240픽셀·피해 1, 최대 3초. 작은 이동 단계로 벽·플레이어·R 조명을 검사하며 벽·조명에 닿으면 소멸
- 근접하면 기존 발톱 공격 사용. 발사 후 1.8초 재사용 간격, 적당 진행 중인 탄은 최대 1개
- 발사 중 이동한 플레이어를 추적 조준하지 않아 달려서 뒤로 돌아가거나 점프로 탄을 피할 수 있음
- 일시정지·창 비활성화 때 탄도 정지. 복구·사망 복귀·재시작은 탄을 정리하고, 처치 전 이미 발사한 탄은 벽·빛·수명 판정까지 유지
- Shade는 같은 구간·6타일 안에서 플레이어를 발견하면 추적. 벽·발판 끝에서 멈춤
- 평소에는 생성 위치 근처 44픽셀이 아닌 전투 구간의 실제 걸을 수 있는 바닥을 넓게 순찰. 발판 끝·벽에서는 방향을 바꿈
- 근접 제자리 공격은 0.7초 예고. 거리 60초과~144픽셀의 접근에는 0.45초 예고 후 방향 고정 돌진(360px/s·0.22초), 피해는 공격당 1회다. 점프·후퇴·Q·R로 대응하며 벽·발판 끝·빛을 통과하지 않는다.
- 원거리 조준 초기의 정면 접근은 새 돌진 예고로 바꾸되 발사 직전 0.2초와 이미 발사한 탄은 추적 조준하지 않는다.
- 적 타격에 맞으면 체력 1 감소·공격 취소·1초 무적과 깜빡임

0.5초 자동 폭발은 없으며 벽·천장·바닥 접촉 시 폭발한다. 반경 48픽셀 안의 적마다 피해 1·공격 취소를 한 번 적용하고 가려진 적은 맞지 않는다. 예상 범위선도 벽·바닥 뒤를 가린다. 이미 날아온 그림자 탄은 남고 Q 제압·지속 점등·자해·핵 피해는 없다. 배터리 소모는 없고 지상 투척 자세는 기존 0.32초 동안 이동을 잠근다. 사망 시 던져 소비한 수량은 유지하고 비행 중 광탄을 정리한다. 바닥 없는 낙하·최대 4초 정리는 공중 피해를 만들지 않는다.

충전 변경 후 전체 자동 검사 427개를 통과했다. 실제 SDL 키 입력·1440×810 출력으로 25/50/100% 게이지·좌우/15도 조준·슬롯 취소·놓아서 투척·3마리 동시 피해·일시정지 취소와 병원 상부 조준을 확인했다. 통제한 교전의 예측/실제 폭발 지점 오차는 0픽셀이며 다양한 각도·충전량·갱신 간격의 자동 검사에서는 3픽셀 미만이다. 기록은 상위 작업 폴더의 `tmp/bomb_charge_play`에 보관한다. 일반 플레이의 난이도·완주 시간은 별도 피드백으로 조정한다.

비치명적 낙하는 체력을 줄이지만 보호막을 소비하거나 남아 있는 두 효과를 종료하지 않는다. 사망은 효과를 종료하고 소비 수량을 유지한다. 수동 재시작은 효과 종료와 진입 수량 복원을 함께 처리한다. 일시정지·창 비활성화는 효과 시간을 멈추고 W 명중 정지는 효과 시간을 멈추지 않는다.

## 도시 지도와 관리소

완료 화면에서 도시 지도 → E 관리소로 진입한다. ←/→로 축전·집광·확산을 선택하고 E로 조각 2개에 구매한다. 축전은 최대 배터리 100→140, 집광은 Q 사거리 +25%, 확산은 R 반경 +25%다. 관리소 화면에 현재 강화와 조각·적용 수치를 표시한다.

코어 강화는 한 방문에 한 번이며 지도·완료 화면을 다시 열어도 방문 기록을 유지한다. 강화 완료 후 치료제·광탄·도시 지도 중 ←/→로 선택하고 E로 구매·이동한다. 강화 직후와 재방문에는 도시 지도를 기본 선택한다. 보급품은 각 조각 1개·종류별 최대 2개이며 부족·한도 초과·키 반복에는 소비하지 않는다. 구매는 수량만 늘리고 체력을 즉시 회복하지 않는다. 지도·관리소에서 월드와 효과 시간은 멈추고 체력·배터리·소모품은 유지한다. 축전 구매가 현재 배터리를 충전하지는 않는다.

강화 후 병원 출발 항목으로 이동한다. 새 구역에서 체력·배터리를 회복하고 물품·조각·강화를 이월하며, 병원에서 재시작해도 이월한 자원은 보존한다. 완료 메뉴의 주택가 다시하기는 강화·소비·보상·방문 기록을 진입 상태로 모두 초기화한다.

실제 SDL 입력으로 세 강화 구매와 실제 Q/R 범위 변경, 재진입·E 유지 중복 방지·정지·재시작을 확인했다. 주택가 시작→8마리 교전→퓨즈 왕복→복구→완료→지도→관리소→집광 구매까지 연결 검증을 통과했다.

보급은 첫 교전 뒤 치료제 → 옥상 진입부 광탄 → 옥상 전투 뒤 배터리·연결로 보호막 → 정비실 치료제·배터리·퓨즈 순서다. 속도는 하부 선택 경로에 둔다. 정비실 물품은 64픽셀 간격으로 분리하며 E는 가까운 제어함/미개봉 보급함을 안내와 동일하게 조작한다.

하부 선택 보급고 (1200,96)는 같은 바닥 48픽셀 안의 E로 열어 조각 1개를 즉시 지급한다. 개봉 중 사망·재방문에도 중복 지급하지 않으며 수동 재시작만 진입 상태로 초기화한다. 기본 복구 보상 2개로 강화하고, 보급고의 추가 조각으로 치료제 또는 광탄 1개를 구매할 수 있다. 보급고를 생략해도 강화·지도 복귀는 가능하다.

실제 SDL 입력으로 선택 보급고 우회→재등반→주택가 8마리 교전·퓨즈 왕복→복구→출구→집광 강화→남은 조각으로 광탄 구매까지 연결 검증했다. 별도 입력 비교로 치료제/광탄 구매·보관 한도·잔액 부족·E 유지·재방문·시간 정지·재시작을 확인했다. 자동 조작 검증은 체감 난이도·목표 플레이 시간을 확정하지 않는다.


## 운하 병원 진행

- 주택가 관리소에서 강화 후 병원 출발 E. 장비·물품·조각을 이월하고 체력·배터리는 회복한다.
- 최초 A 공급. 중앙 E로 A/B를 선택해 밝은 복도를 지나 어두운 부품 방으로 들어간다. A 전력 퓨즈와 B 모듈을 분리하면 해당 회로가 꺼지고 입구가 닫힌다. 분리한 회로는 다시 선택해도 켜지지 않는다.
- 복도 두 지점의 4초 카운트다운 후 적이 출현한다. 플레이어 128픽셀 안과 R 조명에서는 생성하지 않는다. 방 안쪽 스위치 E로 문을 수동 개방하고 어두운 복도를 돌아온다. 부품 회수 전에는 미리 문을 고정할 수 없다.

- 부품 분리 뒤 죽으면 방 안쪽 A (912,96) / B (2992,96)에서 재개한다. 부품·정전·열린 문·소비는 유지하고 중앙으로 건너뛰지 않는다. 실제 중앙 귀환 후에는 중앙 체크포인트로 갱신한다.
- A/B 두 순서를 모두 허용한다. 두 부품 중앙 설치 E로 전체 점등·적 소멸·출현 종료·조각 +2, 뒷벽 출구 E로 완료·관리소에 진입한다. 두 번째 강화 후 변전소 출발을 선택한다.

## 중앙 변전소: 차단기·승강기 개발분

1. 병원 복구 후 관리소에서 두 번째 강화 → 변전소 출발 E. 체력·배터리는 회복하고 강화·소모품·조각은 이월한다.
2. 입구 충전기는 E로 반복 충전할 수 있다. 첫 교전 뒤 치료제, 하부 구간 광탄, 상부 진입부 보호막을 회수한다.
3. 하부 1번 차단기 E로 승강기를 가동한다. 플랫폼 위 E로 상부 이동, 위·아래 호출 패널 E로 빈 승강기를 부른다. 이동 중에는 탑승자 조작을 제한하며 Esc 일시정지는 가능하다.
4. 상부는 엄폐물 앞의 근접·원거리 교전과 뒤쪽 근접 교전으로 나눴다. 높이 48 배전반이 탄을 막으며 기본 점프로 넘을 수 있다. 2번 차단기를 켜고 승강기로 하부에 복귀한다.
5. 배터리 0에서도 하부로 돌아와 입구 충전기까지 이동할 수 있다. 상부 체크포인트에서 부활하면 아래로 복원된 승강기를 호출한다. 차단기·수량·소비는 보존하며 배터리는 사망으로 회복하지 않는다.

현재는 변전소 이동 설비까지 구현했다. 그림자 핵 약화·최종 봉쇄·도시 전체 점등·엔딩은 다음 작업이다. 차단기 2개만 켜면 게임이 끝나는 단계가 아니다.

검증: 단위 검사 401개 통과. 실제 SDL 조작으로 하부 교전→승강기→상부 교전·차단기→하부 복귀→배터리 0의 사망→상부 부활·호출→입구 충전(0→100)을 확인했다. 이 경로에서 사망 1회가 있었으며 진행을 보존한 뒤 재충전에 성공했다. 자동 조작 결과는 초회 난이도·목표 시간을 확정하지 않는다.

## 하단 안내와 광륜 제한

하단 왼쪽에 현재 무기·사용 상태와 두 줄 키캡을 정렬한다. 이동/달리기/점프/상호작용과 공격/섬광/투광기/메뉴를 나누고 광탄·광륜 조준 중에는 방향·각도·놓기·취소 안내로 바뀐다. 오른쪽에는 1~4 슬롯·F 사용, 그 위에는 시간제 효과만 표시한다. 기존의 떠 있던 무기 설명과 반복된 조준 문장을 제거했다.

광륜은 발사 순간 배터리 10, 복귀·지형 회수·수명 정리 뒤 1초 대기다. Q/R과 자원을 공유하며 무기 전환·키 유지로 제한을 우회하지 못한다. 조준해도 적과 월드는 계속 움직인다. 현재 무기 옆에서 준비·비행·재사용 시간·배터리 부족을 확인한다. 광검은 기존처럼 무소비다.

최신 검사 476개와 실제 SDL 입력·1440×810 출력으로 비용·취소·복귀 대기·일시정지·부족 상태·키캡/인벤토리/시간제 효과/조준 화면을 확인했다. 초기 제한값의 체감 난이도는 실제 플레이 피드백으로 조정한다.
