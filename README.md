# Blackout

Python과 pico2d로 개발하는 횡스크롤 2D 탐색·퍼즐 액션 게임.
게임 규칙과 개발 순서는 [PRD.MD](PRD.MD)에서 관리한다.

## 실행

Python이 설치된 환경에서 이 프로젝트 폴더의 터미널을 열고 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지 경로는 소스 파일의 위치를 기준으로 찾으므로 다른 폴더에서 실행해도 된다.
타이틀에서 위/아래로 선택하고 E로 시작한다.
플레이 중 Esc를 누르면 계속하기·스테이지 재시작·타이틀로·나가기를 선택할 수 있다.

## 현재 구간 확인 순서

1. 타이틀에서 E로 시작한 뒤 방향키와 Space로 첫 상자를 넘어간다.
2. Shade와 W로 전투하거나 R로 조명을 설치해 후퇴하는 반응을 확인한다.
   Space로 점프한 뒤 W를 누르면 전방 아래쪽을 한 번 벤다. 착지 후 새 W 입력으로 지상 공격을 이어갈 수 있다.
3. 서로 떨어진 높이 144→192→240픽셀의 발판을 건너 288픽셀 높이의 옥상에 오른다. 위층 적 구간을 지나 오른쪽 끝 정비 선반의 퓨즈를 회수하면 그 지점이 안전한 사망 복귀점이 된다.
4. 옥상 오른쪽에서 192픽셀 높이의 하강 발판으로 내려가 적 구간 뒤의 배터리 팩을 회수한다. 팩은 최대 50 충전하며 가득 차 있으면 남긴다. 지상으로 우회해 두 아이템을 바로 얻거나 하강 발판에서 퓨즈 옥상으로 역진입할 수 없다.
5. 보급 발판 뒤에서 한 단 올라 위층 교량 제어함에 E로 퓨즈를 설치한다. 구간 점등·적 소멸·제어함 앞 복귀 지점 확보가 함께 적용된다. 지상에서는 제어함을 조작할 수 없다.
6. 2.4초 동안 교량 잠금 해제→전개→결합이 진행된다. 안전 차단봉이 내려가면 통행할 수 있고, 복구 보상 전력 조각 2개를 한 번 받는다.
7. 다리를 건너 병원 표지판 아래 출구에서 E를 누르면 주택가 완료 화면으로 이동한다. 현재는 다시하기·타이틀로 돌아가기를 제공한다.
8. Esc 메뉴에서 일시정지와 재시작을 확인한다. 재시작하면 획득·복구·보상·자원을 모두 구간 진입 당시로 되돌린다.

E 설비 복구는 배터리를 사용하지 않는다. R의 8초 조명과 달리 복구 상태는 사망해도 유지된다.
퓨즈 없이 E를 누르면 필요한 부품을 안내한다. 운하는 12타일(384픽셀) 폭이며, 기본 점프와 속도 30% 증가로도 복구 전 다리를 우회할 수 없다.

## 현재 구현

- 기본 표시 창 1440×810. 작은 모니터에서는 사용 가능한 크기에 맞춤
- 복구 전에는 월드에 어둠을 적용하고 기본 랜턴이 주변만 약하게 드러냄. 랜턴은 배터리 소모·적 억제 없음
- R의 실제 64픽셀 억제 범위에 강한 시야를 연결. 설치 위치에 고정되고 소등·만료 시 그 빛만 사라짐
- 전력 복구 시 1.2초 동안 구역 전체의 어둠이 걷힘. 적 소멸은 즉시 적용하고 다리 통행은 2.4초 전개 완료 후 허용
- 발판 윗면·끝 윤곽과 공격 예고·조준선·탄·명중 효과·HUD는 어둠 밖에서 별도로 표시
- 창 테두리를 드래그해 크기 조절 가능. 화면 비율과 게임 좌표 960×540 유지
- 확정한 Warden 대기 이미지와 6프레임 걷기 시트: 캐릭터 높이 약 96픽셀
- 발바닥을 기준으로 한 배치와 몸통 충돌 영역의 초기 크기 정의
- ←/→로 좌우 이동, 이동 방향에 맞춰 이미지 반전, 키를 놓으면 정지
- Shift를 누르며 이동하면 초당 208픽셀 달리기. 전용 6프레임과 실제 이동 거리 기준 보폭 사용
- 달리기 중 점프의 높이·중력은 같고 수평 거리가 늘어남. 무적·체력 회복·배터리 소비는 없음
- Space로 약 2타일 높이 점프. 공중 방향 전환, 중력과 바닥 착지
- 수직 속도에 따라 상승·정점·하강 이미지 전환, 착지하면 대기·걷기로 복귀
- W로 지상 1타, 시작 후 0.4초 안에 W를 다시 눌러 올려베기 2타 연결. 각 타격에 전용 6프레임 사용
- 준비 0.10초·타격 0.10초·회수 0.16초로 재생하고, 공격 중 이동·점프 중복 방지
- 2타는 준비 0.12초·타격 0.12초·회수 0.20초. 미리 입력한 2타는 1타 동작이 끝난 뒤 시작
- 2타 후 0.5초 대기. 키 누르기 반복으로 자동 연격하지 않으며 세 번째 타격은 예약하지 않음
- 2타 명중 시 적을 약 1타일 밀어냄. 벽·발판 끝·전투 구간 밖으로 밀지 않고 사망 시에도 짧은 밀림 표현
- 준비 자세를 길게 읽히고 타격 자세로 빠르게 전환. 발 기준으로 상체가 뒤로 힘을 모았다 앞으로 기울어지는 시각 회전
- 실제 W 명중 때만 공격자와 맞은 적에 0.04초 정지, 2타는 0.055초·처치는 0.065초. 빈 공격에는 정지 없음
- 명중 교차 지점에 짧은 금빛 섬광과 보라색 그림자 파편. 2타·처치에만 최대 2~3픽셀의 짧은 수평 화면 흔들림
- 히트스톱은 두 배우의 동작·이동·공격 시간만 멈추며 조명 수명·맵 설비·다른 적·플레이 시간은 계속 진행
- 히트스톱 도중 새로 누른 W는 재개 시 처리. 피격·사망·재시작 시 공격자의 정지 상태도 해제
- 타격 구간에서만 전방 1타일 판정. 벽 너머 제외, 가까운 대상 한 명을 공격당 한 번 선택
- 공중 W는 전용 6프레임 내려베기. 준비 0.10초·타격 0.12초·회수 0.12초, 피해 1·배터리 소모 없음
- 공중 베기 중 좌우 이동·중력·점프 궤적 유지. 공격 방향만 고정하고 무적·추가 도약·강제 하강은 부여하지 않음
- 점프·발판 이탈부터 다음 착지까지 공중 베기 한 번. 피격·키 반복으로 사용 횟수를 초기화하지 않음
- 착지 시 공중 동작을 종료하고 새 W 입력으로 지상 1타 시작. 지상 2연격 후 대기 시간은 점프로 우회할 수 없음
- 공중 타격은 전방 1타일·발 기준 아래 16~위 48픽셀. 벽·발판 아래를 가려 가까운 한 명에게 한 번만 피해
- Q는 손목 장치의 섬광을 전방 3타일로 발사. 전용 6자세·짧은 금빛 부채꼴로 표현하며 가까운 적 한 명에게 피해 1
- Q 한 번에 배터리 20, 재사용 간격 0.6초. 빈 발사도 소비하고 키 유지·재사용 대기·배터리 부족에는 중복 소비 없음
- Q 명중 시 근접 타격·원거리 조준과 같은 갱신의 발사까지 취소. 적을 최대 48픽셀 밀고 1.2초 제압하며 금빛 표시와 남은 시간 막대를 표시
- 밀림은 벽·발판 끝에서 멈춤. 제압 후 빛 안이면 후퇴하고, 어둠에서는 추적·새 공격 예고부터 재개
- Q 뒤 달려가 W로 마무리하거나 Q 두 번으로 처치 가능. 이미 발사된 그림자 탄은 계속 날아오므로 점프·달리기 또는 R로 대응
- 새 전투 키가 겹치면 R → Q → W 중 하나만 처리. 기존 동작 중 다른 액션을 중첩하지 않으며 공중 Q는 점프 궤적 유지
- Space를 계속 눌러도 재점프하지 않으며 착지 후 다시 눌러야 함
- 벽·천장·계단형 발판과 몸통 영역의 충돌. 발판에서 걸어 나가면 낙하
- 낙하 시 체력 1 감소와 마지막 안전 발판 복귀. 체력 소진 시 지정 안전 지점·체력 3으로 복귀
- 낙하 복귀 후 1초 깜빡임. 복귀 직후에는 방향키를 다시 눌러 이동
- 경과 시간 기준 초당 128픽셀 이동, 맵 바깥 이동 제한
- 양쪽 방향키를 함께 누르면 정지. 창이 비활성화되면 이동 입력 해제
- 창이 비활성화된 동안 이동·적 행동·공격·효과 시간을 멈춤
- 실제 이동 거리에 맞춰 걷기 재생. 키를 놓거나 화면 끝에서 멈추면 대기 자세
- 프레임마다 발 기준점을 맞추고 몸통 영역은 일정하게 유지
- 세 화면 길이(2880픽셀)의 주택가와 수평 추적 카메라. 카메라는 맵 양끝에서 정지
- 지상 96픽셀, 상승 발판 144·192·240픽셀, 옥상 288픽셀, 보급 발판 192픽셀, 교량·제어함·출구 224픽셀로 연결
- 상승용 얇은 발판은 아래·옆으로 통과하고 내려올 때 윗면에 착지. 사이로 떨어지면 지상에서 왼쪽 첫 발판으로 돌아가 재등반 가능
- 교량 양쪽 지상에 높이 144·192픽셀의 복귀 발판을 추가. 아래에서 224픽셀 제어함·출구 높이로 돌아올 수 있으며 기존 벽·천장·보급 발판의 충돌은 유지
- 옥상 적 구간 뒤에 퓨즈, 하강 발판 적 구간 뒤에 배터리 배치. 층이 다른 지상에서 아이템을 접촉 획득하지 않음
- 퓨즈 접촉 회수 후 제어함 근처 바닥에서 E로 구간 복구. 배터리 소모 없음
- 운하 폭을 기존 192에서 384픽셀로 확장. 교각·금속 상판·보강재·난간·힌지·와이어를 갖춘 양엽식 교량
- 다리는 2.4초 전개 완료 시 충돌 영역 추가와 안전 차단 해제. 사망 시 복구된 다리는 펼쳐진 상태 유지
- 배터리 팩 1개, 접촉 시 최대 50 회복. 최대치일 때는 미획득 상태 유지
- 다리 복구 보상 조각 2개. 사망·E 재입력으로 중복 획득하지 않음
- 복구 시 구간 점등·적 소멸·안전 지점 확보. 사망해도 복구 상태 유지
- Shade 8마리를 첫 구간 2·옥상 3·보급 발판 3마리로 배치. 근접 5·원거리 겸용 3마리
- 원거리 적은 최대 384픽셀에서 발견하고 같은 구간·같은 층·시야가 열린 112~352픽셀 거리에서 조준 시작
- 0.65초 동안 조준선과 손의 발광으로 예고. 예고 시작 위치를 고정해 발사하며 이후 유도하지 않음
- 그림자 탄은 초당 240픽셀·피해 1, 최대 3초. 작은 이동 단계로 벽·플레이어·R 조명을 검사하며 벽·조명에 닿으면 소멸
- 근접하면 기존 발톱 공격 사용. 발사 후 1.8초 재사용 간격, 적당 진행 중인 탄은 최대 1개
- 발사 중 이동한 플레이어를 추적 조준하지 않아 달려서 뒤로 돌아가거나 점프로 탄을 피할 수 있음
- 일시정지·창 비활성화 때 탄도 정지. 복구·사망 복귀·재시작은 탄을 정리하고, 처치 전 이미 발사한 탄은 벽·빛·수명 판정까지 유지
- Shade는 같은 구간·6타일 안에서 플레이어를 발견하면 추적. 벽·발판 끝에서 멈춤
- 평소에는 생성 위치 근처 44픽셀이 아닌 전투 구간의 실제 걸을 수 있는 바닥을 넓게 순찰. 발판 끝·벽에서는 방향을 바꿈
- 근접하면 0.7초 경고 후 한 번 타격, 약 1초 뒤 재판단. 예고 중 방향 고정
- 적 타격에 맞으면 체력 1 감소·공격 취소·1초 무적과 깜빡임
- W 유효 타격마다 Shade 체력 1 감소. 두 번 맞으면 공격을 멈추고 0.8초 동안 소멸
- W의 첫 명중은 적의 예고를 취소하지 않으며, 몸 접촉만으로는 피해가 발생하지 않음
- 체력 소진 시 플레이어는 지정 안전 지점으로 복귀. 복구 전에는 적을 초기화하고 복구 후에는 소멸 상태 유지
- Shade의 걷기 4프레임·예고·타격 자세, 전용 피격 3자세·쓰러짐 3자세 연결
- 1타·공중 타격은 짧은 반동, 2타는 크게 젖혀짐. 비치명타는 공격 예고를 취소하지 않고 실제 적 타격 자세를 우선 표시
- 단검 처치는 젖혀짐·무릎 꺾임·쓰러짐 후 소멸. 전력 복구로 사라질 때는 기존 점등 소멸 표현 사용
- 배터리 100으로 시작. R 새 입력마다 50을 사용해 현재 좌표에 8초 조명 설치
- 바닥에 착지한 상태에서 설치. 공중 입력은 소비·예약 없이 안내하고 기존 조명을 유지
- 몸 낮추기·장치 조작·일어서기의 3자세를 0.18초 동안 재생. 이동·점프·공격 중복 방지
- 동시에 조명 하나 유지. 재설치는 이전 조명을 교체하고, 배터리 부족 시 미발동·미소비
- 사망 시 조명은 종료하지만 배터리 잔량은 유지. 배터리 0에서도 이동·점프·W 가능
- 빛에 노출된 Shade는 공격을 취소하고 가까운 어둠으로 후퇴. 벽·발판 끝에서는 정지
- 빛 안에서 대기 중이면 다시 탈출 경로를 찾으며, 장애물에 막혔다가 길이 열려도 후퇴 재개. 조명은 피격 정지보다 우선 적용
- 빛에서 빠져나온 적은 어두운 바닥에서 순찰을 이어감. 빛 경계에서 멈추거나 반복 후퇴하지 않고 방향을 돌려 계속 걷기
- 플레이어가 같은 어두운 쪽으로 나오면 다시 추적. 조명이 사이에 있거나 플레이어가 빛 안에 있으면 어둠 순찰 유지
- 새 조명은 새 위치로 재판단. 소등 후 순찰·추적을 재개하며 공격은 새 예고부터 시작
- 금속 베이스·접이식 발·발광 코어·반사판이 있는 전용 장치 스프라이트. 접힘·전개·점등 3단계
- 점등 직후부터 보호 범위를 비추고 0.22초에 걸쳐 빛을 강화. 부드러운 주변광·반사광·바닥 빛·작은 먼지 입자 표현
- 남은 2초는 밝기 변화로 소등 예고, 마지막 0.45초 감쇠. 장치 밑 세 칸 전력 표시와 HUD 남은 시간 제공
- 빛·반사광은 방·통로 영역 안에 표시. 8초 만료와 동시에 장치·빛·적 억제 종료
- 흰색 알파 텍스처 하나를 광원마다 색·크기만 바꿔 재사용. 종료 시 효과 리소스 해제
- 운하 도시의 투명 배경 원화와 원경·중경·전경의 스크롤 속도 구분
- 돌길·목재 상자·가로등·구역 표지판·수면 반사, HUD 뒤의 어두운 반투명 배경 적용
- Esc로 일시정지·계속하기. 메뉴에서 타이틀 이동·나가기 선택
- 일시정지 중 이동·적·조명·효과·플레이 시간 모두 정지
- 일시정지의 스테이지 재시작은 위치·체력·배터리·설비·적을 진입 상태로 함께 복원
- 사망은 최신 배터리와 복구 상태를 유지하고 지정 안전 지점에서 체력만 회복
- 플레이 시간은 사망·재시작으로 되돌리지 않으며, 기록은 실행 중 메모리에 보관

F1을 누르면 발 기준점(노란 십자), 몸통(초록), 지형(파랑), 유효 공격 범위(빨강)를 표시한다.
플레이어와 Shade 모두 실제 공격 범위와 몸통 영역의 겹침으로 피해를 판정한다.

현재는 주택가의 퓨즈 획득 → 전력 복구 → 다리 통과 → 출구 완료를 연결한 단계다.
W는 지상 2연격과 점프당 한 번의 공중 베기를 제공하며 기본 이동·전투·조명 반응을 사용할 수 있다.
복구 전에는 사망 시 적이 다시 나타난다. 복구 후에는 사망해도 적이 다시 나타나지 않는다.
R은 설치 당시 좌표에 고정되고, 캐릭터가 이동해도 따라오지 않는다.
어두운 구역의 적 추가 출현·치료제 보급함·회복은 2주차 후속 작업이다.
인벤토리·관리소·병원·변전소·전체 엔딩은 아직 연결하지 않았다.
배터리는 100으로 시작하고 주택가 팩으로 한 번 충전할 수 있으며,
메뉴의 스테이지 재시작으로 반복 확인할 수 있다. 재시작은 배터리와 함께 복구 상태·적·위치도 초기화한다.
사망은 배터리를 회복하지 않으며, 일시정지 중에는 조명과 플레이 시간을 포함한 모든 갱신을 멈춘다.

1주차의 기본 기능을 바탕으로 2주차 앞부분인 주택가의 필수 진행을 연결했다.
진입 기록과 최신 기록은 실행 중 별도로 보관하며, 프로그램을 종료하면 사라진다.
전투 확장 후 초회 완주 시간·사망 원인을 측정해 탐색 동선과 전투 배치를 조정한다.

SDL의 실제 키 이벤트로 시작부터 퓨즈 획득·사망 부활·배터리 회수·복구·다리 통과·완료·재시작까지 확인했다.
1440×810 소프트웨어 렌더링으로 조명·정비소·운하의 복구 전후·완료 화면을 확인했다.
공중 베기는 실제 SDL 키 이벤트로 좌우 방향의 6프레임·단일 타격·공중 재사용 제한·일시정지·착지 공격을 확인했다.

조명은 실제 SDL 입력으로 좌우 설치 자세·전개·점등·소등 예고·정확한 만료와 적 후퇴를 확인했다.
설치 중 일시정지·창 비활성화 때 자세와 수명이 함께 멈추고, 기존 주택가 완주 경로도 유지되는지 검증했다.
변경한 맵도 실제 키 입력으로 상승 발판→옥상 적 구간→퓨즈→사망 복귀→하강 배터리→복구→교량 통과→완료·재시작을 확인했다.
지상 공격 예고·타격 중, 2층에서 각각 R로 적의 공격 취소와 어둠까지의 후퇴를 검증했다.

실제 SDL 입력으로 정지 시 원거리 피격, 달리기+점프 회피, 조준 중 뒤로 달려가기 회피를 비교했다. 현재 옥상 혼합 교전에서도 피해 없이 탄을 넘는 동작을 확인했다.

어둠·이동 랜턴·설치 조명·소등·영구 복구를 실제 SDL 화면으로 비교하고, 변경 후 주택가 완주·달리기/점프 회피를 다시 확인했다.
