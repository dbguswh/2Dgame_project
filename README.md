# Blackout

Python과 pico2d로 개발하는 횡스크롤 2D 탐색·퍼즐 액션 게임.
게임 규칙과 개발 순서는 [PRD.MD](PRD.MD)에서 관리한다.

## 실행

Python이 설치된 환경에서 이 프로젝트 폴더의 터미널을 열고 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

이미지 경로는 소스 파일의 위치를 기준으로 찾으므로 다른 폴더에서 실행해도 된다.

## 현재 구현

- 기본 표시 창 1440×810과 임시 바닥. 작은 모니터에서는 사용 가능한 크기에 맞춤
- 창 테두리를 드래그해 크기 조절 가능. 화면 비율과 게임 좌표 960×540 유지
- 확정한 Warden 대기 이미지와 6프레임 걷기 시트: 캐릭터 높이 약 96픽셀
- 발바닥을 기준으로 한 배치와 몸통 충돌 영역의 초기 크기 정의
- ←/→로 좌우 이동, 이동 방향에 맞춰 이미지 반전, 키를 놓으면 정지
- Space로 약 2타일 높이 점프. 공중 방향 전환, 중력과 바닥 착지
- 수직 속도에 따라 상승·정점·하강 이미지 전환, 착지하면 대기·걷기로 복귀
- W 새 입력으로 지상 단발 베기. 큰 몸 비틀기·팔 뻗기·베기·회수의 6프레임
- 준비 0.10초·타격 0.10초·회수 0.16초로 재생하고, 공격 중 이동·점프 중복 방지
- 타격 구간에서만 전방 1타일 판정. 벽 너머 제외, 가까운 대상 한 명을 공격당 한 번 선택
- Space를 계속 눌러도 재점프하지 않으며 착지 후 다시 눌러야 함
- 벽·천장·계단형 발판과 몸통 영역의 충돌. 발판에서 걸어 나가면 낙하
- 낙하 시 체력 1 감소와 마지막 안전 발판 복귀. 체력 소진 시 시작점·체력 3으로 복귀
- 낙하 복귀 후 1초 깜빡임. 복귀 직후에는 방향키를 다시 눌러 이동
- 경과 시간 기준 초당 128픽셀 이동, 맵 바깥 이동 제한
- 양쪽 방향키를 함께 누르면 정지. 창이 비활성화되면 이동 입력 해제
- 창이 비활성화된 동안 이동·적 행동·공격·효과 시간을 멈춤
- 실제 이동 거리에 맞춰 걷기 재생. 키를 놓거나 화면 끝에서 멈추면 대기 자세
- 프레임마다 발 기준점을 맞추고 몸통 영역은 일정하게 유지
- 두 화면 길이의 구간과 수평 추적 카메라. 카메라는 맵 양끝에서 정지
- 계단·천장·상자와 2타일 너비의 물 구간을 이동하며 확인 가능
- 첫 상자와 계단 사이에 조명 후퇴를 확인할 평지 확보
- 첫 상자 뒤에 Shade 한 마리 배치, 발 위치·몸통 영역·체력 2칸 표시
- Shade는 같은 구간·6타일 안에서 플레이어를 발견하면 추적. 벽·발판 끝에서 멈춤
- 근접하면 0.7초 경고 후 한 번 타격, 약 1초 뒤 재판단. 예고 중 방향 고정
- 적 타격에 맞으면 체력 1 감소·공격 취소·1초 무적과 깜빡임
- W 유효 타격마다 Shade 체력 1 감소. 두 번 맞으면 공격을 멈추고 0.8초 동안 소멸
- W의 첫 명중은 적의 예고를 취소하지 않으며, 몸 접촉만으로는 피해가 발생하지 않음
- 체력 소진 시 플레이어와 적의 시작 위치·체력·동작을 복원
- Shade의 걷기 4프레임·예고·타격 자세와 피격 깜빡임·소멸 표현 연결
- 배터리 100으로 시작. R 새 입력마다 50을 사용해 현재 좌표에 8초 조명 설치
- 동시에 조명 하나 유지. 재설치는 이전 조명을 교체하고, 배터리 부족 시 미발동·미소비
- 사망 시 조명은 종료하지만 배터리 잔량은 유지. 배터리 0에서도 이동·점프·W 가능
- 빛에 노출된 Shade는 공격을 취소하고 가까운 어둠으로 후퇴. 벽·발판 끝에서는 정지
- 어둠에 도착하면 밝은 플레이어를 다시 쫓지 않고 대기. 소등 후 새 공격 예고부터 재개
- 따뜻한 원형 빛과 범위 테두리, 설치 장치·배터리·남은 시간 표시
- 창 닫기 또는 Esc로 종료

F1을 누르면 발 기준점(노란 십자), 몸통(초록), 지형(파랑), 유효 공격 범위(빨강)를 표시한다.
플레이어와 Shade 모두 실제 공격 범위와 몸통 영역의 겹침으로 피해를 판정한다.

현재는 대기·걷기·점프·지상 단발 베기를 연결한 단계다.
점프·중력·바닥·벽·천장·발판 충돌을 구현했다.
첫 상자 뒤에서 Shade 한 마리와 기본 전투를 할 수 있다.
처치 후에는 빈 구간을 탐색할 수 있고, 재실행하거나 사망하면 적을 다시 확인할 수 있다.
R은 설치 당시 좌표에 고정되고, 캐릭터가 이동해도 따라오지 않는다.
전력 복구·적의 추가 출현은 후속 개발 범위다.
배경과 바닥은 기능 확인용 임시 표현이다.
배터리는 현재 100으로 시작하므로 R을 두 번 설치할 수 있다. 보급·충전은 후속 작업이며,
반복 확인을 위해 새로 실행하면 시작 상태로 돌아간다. 사망은 배터리를 회복하지 않는다.

1주차의 이동·전투·빛 반응을 한 구간에 연결했다.
타이틀에서 플레이 진입, E 설비 상호작용, 진행 기록과 수동 재시작은 남은 1주차 작업이다.
