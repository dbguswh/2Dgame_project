# 캐릭터 이미지

- `player.png`: 확정한 Warden의 대기 이미지
- `shade.png`: 확정한 Shade의 정지 이미지
- `player_walk.png`: Warden의 오른쪽 방향 걷기 6프레임 시트
- `player_walk.json`: 각 프레임의 잘라 그릴 영역과 발 기준 좌표
- `player_actions.png`: 윗줄은 상승·정점·하강, 아랫줄은 베기 준비·타격·회수
- `player_actions.json`: 점프·베기 프레임과 발 기준 좌표
- `player_attack.png`: 몸을 비틀고 팔을 크게 쓰는 개선된 단발 베기 6프레임
- `player_attack.json`: 개선된 베기 프레임과 발 기준 좌표
- `shade_motion.png`: Shade 걷기 4프레임·공격 예고·앞발 타격
- `shade_motion.json`: Shade 동작과 발 기준 좌표

걷기 시트는 1536×1024 투명 PNG이며, 512×512 칸을 가로 3개·세로 2개로 배치했다.
윗줄 왼쪽부터 읽고 아랫줄로 이어진다. 왼쪽 동작은 게임에서 좌우 반전한다.
프레임 좌표와 발 좌표는 pico2d의 왼쪽 아래 기준이다.
게임에서 공통 배율과 프레임별 발 기준점을 사용해 바닥에 맞춰 그린다.
걷기 한 주기는 게임 좌표 64픽셀 이동에 맞춘 초기값이다.

2026-11-06에 내장 imagegen 도구로 `player.png`를 참조해 제작했다.
생성된 PNG의 투명도를 유지했으며 원본 대기 이미지는 변경하지 않았다.
제작에 사용한 전체 프롬프트는 `player_walk.prompt.txt`에 기록했다.

점프·베기 시트 역시 내장 imagegen으로 같은 확정 이미지를 참조해 제작했다.
원본 1536×1024 PNG를 유지하고 프레임마다 발 기준을 따로 정의했다.
공중에서 다리를 구부리는 자세는 크기를 늘리지 않고 그리며,
몸통의 실제 충돌 크기는 이미지 변화와 독립적으로 유지한다.
전체 프롬프트는 `player_actions.prompt.txt`에 기록했다.

베기 개선 시트는 같은 날 내장 imagegen으로 확정 외형과 기존 동작 시트를
참조해 제작했다. 준비·몸 비틀기·타격·후속 동작·회수·대기 복귀의 6프레임이다.
기존 `player_actions.png`는 점프에 사용하고, 실제 베기는 `player_attack.png`를 사용한다.
몸통 크기를 확대하는 대신 어깨·팔·상체·무릎 동작을 크게 만들었다.
짧고 밝은 칼 궤적의 가장자리 발광은 별도의 원거리 공격 판정이 아니다.
제작 프롬프트는 `player_attack.prompt.txt`에 기록했다.

Shade 동작 시트는 2026-11-06에 내장 imagegen으로 확정한 `shade.png`를 참조해
제작했다. 3열·2행의 투명 PNG로, 각 셀의 발 기준점을 맞춰 그린다.
왼쪽을 보는 원본 동작을 사용하고 오른쪽 동작은 게임에서 반전한다.
공격 예고는 밝은 눈·팔과 준비 자세, 타격은 낮은 앞발 휘두르기로 구분한다.
최종 시트는 셀 사이 여백을 보정해 가시 영역이 이웃 셀로 넘어가지 않도록 했다.
생성 및 보정 프롬프트는 `shade_motion.prompt.txt`에 기록했다.
